Before you use CoX Raid Dashboard

This dashboard runs on your computer and reads RuneLite data locally.

  • It reads your selected .runelite CoX raid log and Boss Kills screenshots.
  • It serves the dashboard only on 127.0.0.1, which is your own computer.
  • Raid data and screenshots are not uploaded by this application.
  • Your selected RuneLite folder and screenshot account are saved locally under your Windows user profile.
  • The application does not modify your RuneLite raid log or screenshots.
  • The application is open source so its local-data behavior and release build process can be reviewed.
